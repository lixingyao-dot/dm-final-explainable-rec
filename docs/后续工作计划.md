## 一、学术&模型：提出 TA-ItemCF（核心创新）

### 1.1 为什么需要 TA-ItemCF

你的实验已证明两件事：
1. ItemCF（纯协同过滤）不输NCF（深度学习）→ 简单方法被低估
2. 时序衰减一致有效（+15%）→ 时间是关键信号

但这两件事目前是割裂的——时序衰减用在NCF的BCE loss里，ItemCF完全没用到时间信息。**把时序信号融入ItemCF，你就有了一个新算法。**

### 1.2 TA-ItemCF 的设计

标准 ItemCF：两个物品的相似度 = 共同交互用户数 / 各自用户数的几何平均（余弦相似度），所有交互权重相同。

**TA-ItemCF**：计算物品相似度时，每次共同交互按时间衰减加权。

```
标准 ItemCF:
  sim(A, B) = (U_A · U_B) / (|U_A| × |U_B|)

TA-ItemCF:
  sim(A, B, t) = Σ w(t, t_ui) / (|U_A| × |U_B|)
  
  w(t, t_ui) = exp(-λ × (t - t_ui) / T_span)
```

直觉：用户在两年前买了A、昨天买了B，和用户昨天买了A、今天买了B，后者对"AB相似"的贡献应该更大。

### 1.3 实验对比

| 模型 | H@10（大数据集预期） | 可解释性 |
|------|---------------------|---------|
| ItemCF | 0.339 | ★★★ |
| NCF | 0.341 | ★ |
| NCF+Temporal | 0.392 | ★ |
| TA-ItemCF | ? | ★★★ |

如果 TA-ItemCF 超过 0.392，你就是**同时拿到最高准确率和天然可解释性**。即便略低于 NCF+Temporal，也可以论证"接近最优性能 + 完全可解释"是更好的工程选择。

### 1.4 实现量

## 三、解释：从"有解释"到"解释可信"

### 3.1 ItemCF explain()（行为解释）

查相似度矩阵，输出桥接物品 + 理由文本，~30行。

### 3.2 时序权重归因（行为解释）

`TemporalExplainer`：回查用户历史，按时间权重排序，~50行。

### 3.3 解释保真度评估（学术加分）

**定义**：解释是否真实反映了推荐逻辑？

**方法**：对于"推荐A是因为你买过B"，移除B后重新计算A的推荐分数。分数下降越多，证明B确实贡献越大。

输出 fidelity score："平均移除桥接物品后推荐分数下降X%"。这是可解释性研究的标准评估方法。

### 3.4 案例分析

选3-5个代表性用户（冷启动/活跃/季节性购买者），完整展示推荐+解释链路，定性分析作为论文Case Study。
